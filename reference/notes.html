robertthepatrick.com — canonical CSS/JS

This is the single source of truth for the shared template patterns across the 26 published pages: header, nav, buttons, type scale, hero/band/section primitives, footer, the custom cursor, and the header-tone script. It is assembled from the confirmed common core found across the site on 15 Nov 2026, plus three fixes that were drift on most pages but should be universal.

No live page points at these files directly — each artifact is a standalone document and can't include another one's files. This exists so any future build or audit has a fixed baseline to build from or diff against, instead of re-deriving "what's canonical" from majority vote across the whole site again.
